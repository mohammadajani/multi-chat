YouTube — Sign in with Google

Connects to an account and automatically pulls chat from whatever it's currently live-streaming — no video ID needed. Sign in again to add a second account (e.g. your other channel, or a friend's).

One-time setup: create a free OAuth Client ID in Google Cloud Console (APIs & Services → Credentials → OAuth client ID → type "Web application"), enable "YouTube Data API v3", and add as an authorized redirect URI.
